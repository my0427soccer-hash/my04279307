# 相互評価レーダー

グループのメンバーが互いを他人評価し、結果をレーダーチャートとランキングで見る
ツールです。参加者の名前はアプリの中で自由に入力でき、3人から12人まで対応します。
`index.html` 1ファイルだけで動き、サーバーもビルドも不要です。
スマートフォンのホーム画面に追加すれば、アプリとして全画面で起動します。

## 使い方

### 1. 参加者を決める（最初の1回だけ）

`index.html` を開くと、まず参加者の設定画面が出ます。

1. 名前を1行に1人ずつ入力する（3〜12人、各12文字まで、重複不可）
2. 配点を選ぶ
3. 「この設定で始める」

決めた内容は画面下に確認が出ます（1問で配られる合計pt、1人が取れる最大pt、
回答コードの長さ）。

そのあと「参加者を招待するリンク」を押すと、**同じ参加者・同じ配点が自動で
設定されるURL** が出ます。これを全員に送れば、各自が名簿を入力する必要は
ありません。自動集計を設定してある場合は、サーバー経由でも共有されます。

### 2. 回答する

1. 「回答する」タブで自分の名前を選ぶ
2. **パスワードを決める**（初回のみ。2回目からは同じものを入力）
3. 質問ごとに、自分以外の全員を上位からタップして順位づけする
   （最後の1人を残すまで選ぶと、残りは自動で最下位になります）
4. 全60問おわったら「回答を確定して送信」

自動集計を設定してあれば、そのまま結果に反映されます。設定していない場合は
**回答コード** が表示されるので、集計担当に送ってください。

### 3. 集計する

「結果を見る」タブでパスワード **`My04279307`** を入力します。
自動集計を設定してあれば、開いた時点で全員の回答が読み込まれます。
設定していない場合は、集まった回答コードを貼り付けて「読み込む」。

**結果は参加者全員がそろって初めて表示されます。** 1人でも欠けているあいだは
「あと何人か」と未提出者の名前だけが出て、集計もランキングも一切出ません。
途中経過が見えると、まだ回答していない人がそれに合わせて順位を変えられて
しまうためです。全員そろえば、レーダーも質問別ランキングも全データも
すべて表示されます。

### 4. 各自のパスワードについて

名前を選ぶときのパスワードは、**それぞれが自分で決めます**（結果画面の
`My04279307` とは別物です）。これによって:

- 他の人があなたの名前を選んでも、回答の途中経過を見たり続きを開いたりできません
- 他の人があなたの名前で回答を送信することもできません
- 端末に保存される下書きは、そのパスワードから作った鍵で暗号化されます
  （`localStorage` を直接覗いても、順番は読めません）

忘れた場合は、集計担当が結果画面の「管理」からその人をリセットできます。
リセットするとその人の提出済み回答も消えるので、新しいパスワードで回答し直しになります。

### 5. 結果に出るもの

| セクション | 内容 |
| --- | --- |
| 総合ランキング | 全60問の平均pt順 |
| カテゴリ別レーダー | 1人1枚、10カテゴリの10角形レーダー |
| 重ねて比べる | 選んだ人を1枚に重ねる（最大3人） |
| カテゴリ別ランキング | 10カテゴリ × 参加者全員の平均ptと順位 |
| 質問別ランキング | 全60問それぞれの順位 |
| 全データ | 全数値の表と、表計算ソフトへの貼り付け用テキスト |

## 採点方法

各質問で、評価する側は自分以外の全員（N人中のN−1人）に順位をつけます。
配点は2種類から選べます。以下は **m = N−1**（順位をつける相手の人数）です。

| 方式 | 配点 | 5人（m=4）なら |
| --- | --- | --- |
| 倍々（既定） | 最下位0pt、そこから上に 1, 2, 4, 8 … と倍 | 4 / 2 / 1 / 0 |
| 等差 | m−1, m−2, … 1, 0 | 3 / 2 / 1 / 0 |

倍々は1位に重みが寄ります。人数が多いときは差が極端になるので、
その場合は等差のほうが扱いやすいかもしれません。

自分自身は評価しないので、1人あたり **m人** から評価を受けます。

### 点数の数え方

配点の合計を **S**、参加者を **N人** とすると:

| | 値 | 5人・倍々の例 |
| --- | --- | --- |
| 1問で配られる合計 | S × N | 7 × 5 = **35pt** |
| 1人が1問で取れる最大 | 1位の点 × m | 4 × 4 = **16pt** |
| 1人の1問あたり平均 | S × N ÷ N = S | **7pt** |
| 評価者1人あたりの平均 | S ÷ m | 7 ÷ 4 = **1.75pt** |

画面に出る「平均pt」は最後の **S ÷ m** を基準にした数字です。
1問で配られる合計が S×N になるのは、**点数を配る人がN人いる**ためです
（1人あたりの受け取り側から見た評価者はm人ですが、配る側は全員です）。
レーダーチャートの中央にある薄いゾーンがこの基準値にあたり、
そこから外に膨らんでいるところがその人の強みです。

質問は10カテゴリ × 6問の計60問。カテゴリは
能力・知性／外見・魅力／性格・人間性／コミュニケーション／仕事・お金／メンタル／
身体能力／恋愛・人間関係／クリエイティブ／その他 です。

## 自動集計をセットアップする

コードの受け渡しをなくし、各自の回答が自動で集計に反映されるようにします。
Google アカウントがあれば無料で、10分ほどで終わります。

1. [Google スプレッドシート](https://sheets.new)で新しいシートを作る（名前は何でもよい）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `function myFunction() {}` を全部消し、
   このリポジトリの **`apps-script/Code.gs` の中身を丸ごと貼り付けて保存**
4. 右上の **デプロイ → 新しいデプロイ** をクリック
5. 歯車アイコン → **ウェブアプリ** を選ぶ
6. 設定を次のようにする
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
7. **デプロイ** を押し、権限の確認画面が出たら承認する
   （「このアプリは確認されていません」と出たら、詳細 → 安全でないページに移動 で進める）
8. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/..../exec`）をコピー
9. `index.html` の上のほうにある次の行に貼り付けて保存・push する

```js
var SYNC_URL = "";   ←  ここに URL を貼る
```

これで完了です。参加者名簿は `roster` シートに、回答は `submissions` シートに
1人1行ずつ溜まります。名簿もサーバー経由で全員に共有されるので、招待リンクを
送らなくても参加者設定がそろいます。

**動作確認**: コピーしたURLをブラウザで直接開いて
`{"ok":true,"service":"pr2","people":0,"rows":0}` が表示されれば正常です。

**注意**

- `Code.gs` の `RESULT_PASSWORD` は `index.html` の `PASSWORD` と同じ値にしてください。
  結果の取得とリセットの認証に使っています。
- コードを修正したあとは、**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン:
  新バージョン → デプロイ** で反映してください。新規デプロイし直すとURLが変わります。
- シートに保存されるのは回答コードとパスワードのハッシュだけです。
  パスワードそのものは送信も保存もされません。

## 回答コードについて

60問ぶんの回答を1本の文字列に詰めたものです。1問の順位は m人の並べ方 m! 通りなので、
それを24進数（`I` と `O` を除いた24文字）で表しています。1問あたりの文字数は
人数によって変わります。

```
PR2 ABCD 0A AAAA...AAAA TQ
│   │    │  │              └─ チェックサム2文字（写し間違いの検出用）
│   │    │  └─ 60問ぶんの回答
│   │    └─ 回答者の番号
│   └─ 名簿ID（参加者と配点から決まる。違う名簿のコードを弾くため）
└─ 形式の識別子
```

| 参加者 | 1問あたり | コード全体 |
| --- | --- | --- |
| 3〜5人 | 1文字 | 71文字 |
| 6〜7人 | 3文字 | 191文字 |
| 12人 | 6文字 | 371文字 |

読み込むときは大文字・小文字とスペースを区別しません。名簿IDが違うコードは
「別の参加者設定で作られたコードです」として弾かれるので、名簿の食い違いに
気づかないまま集計してしまうことはありません。

## 注意点

セキュリティの強さについて、正確に書いておきます。

- **結果画面のパスワード（`My04279307`）は覗き見防止です。** ブラウザだけで動く
  ツールなので、ページのソースを見れば読めます。回答した人が結果を先に見てしまう
  のを防ぐためのもので、本気で秘密を守る仕組みではありません。
- **各自のパスワードは、他の参加者に対しては有効です。** ハッシュしか保存・送信
  されないので、他の参加者があなたの順番を見ることはできません。ただし下書きの暗号化
  は自前の簡易な方式（SHA-256から鍵列を作るストリーム暗号）なので、専門知識のある
  人が本気で解析すれば破れます。友人同士の覗き見防止としては十分、という水準です。
- **集計する人は、その気になれば個々の回答を読めます。** スプレッドシートに回答
  コードが並ぶので、解読すれば誰が誰を何位にしたかは分かります。結果画面には集計後
  の数字しか出しませんが、これは仕組み上どうにもなりません。
- 自動集計を設定しない場合、**データは端末のブラウザにだけ残ります。** 別の端末とは
  共有されません。シークレットウィンドウやブラウザのデータ消去に注意してください。
- 参加者を変えると名簿IDが変わり、それ以前の回答コードはすべて無効になります。
  自動集計を設定している場合は、サーバー側の回答も破棄されます。
- 質問そのものを変えたい場合は `index.html` の `CATS` を書き換えてください。

## スマートフォンのアプリとして使う

ホーム画面に追加すると、アイコンから全画面で起動し、電波がなくても開けるように
なります（PWA）。ストアからのインストールや専用アプリは不要です。

**先に GitHub Pages などの https で公開しておく必要があります。**
`file://` で開いた場合やローカルのファイルでは、この機能は動きません。

### iPhone（Safari）

1. Safari でサイトを開く（Chrome など他のブラウザではこの項目が出ません）
2. 下の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して「追加」

### Android（Chrome）

1. Chrome でサイトを開く
2. 「アプリをインストール」の案内が出たらそれをタップ
   （出ない場合は右上の︙メニュー →「アプリをインストール」または「ホーム画面に追加」）

### アプリにすると変わること

- アドレスバーやタブが消えて全画面になる
- ホーム画面にアイコンが並ぶ
- 一度開いたあとは、オフラインでも起動して回答できる
  （回答の送信だけは通信が必要です。圏外で送信に失敗した場合は回答コードが
  表示されるので、あとで「もう一度送信する」を押すか、コードを手渡ししてください）
- ノッチやホームバーを避けて表示されます

オンラインのときは常に最新のファイルを取りに行くので、`index.html` を更新すれば
アプリ側にも反映されます。

### App Store に出す場合

Capacitor で包んだ Xcode プロジェクトを `native/ios/` に用意してあります。
ただし **ビルドと提出には Mac が必須** で、Apple Developer Program
（年12,980円）も要ります。審査で落ちる可能性も含めて、手順と注意点は
**[IOS.md](IOS.md)** にまとめました。

身内で使うだけなら、上のホーム画面追加で実用上ほぼ同じことができます。
先にそちらで運用してから判断することをおすすめします。

## みんなに配る

- **一番かんたん**：`index.html` をそのまま送る（メール添付・チャット等）。
  各自が開いて回答し、出てきたコードを返す。参加者設定は「招待するリンク」で共有できます。
- **リンクで配る**：GitHub Pages を有効にすると
  `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
  リポジトリの Settings → Pages → Source をこのブランチの `/ (root)` に設定してください。
  ホーム画面アプリとして使うにはこの方法（https での公開）が必要です。

## 設計メモ

- 依存ライブラリなし。チャートは素の SVG で描画しています。
- 配色は8色のカテゴリカルパレットの先頭3スロットを使っています。1枚に重ねられるのを
  3人までにしているのは、4色以上を重ねると P型・D型色覚で線が判別できなくなるためです。
  重ねるときは色に加えてマーカーの形（●■◆）でも区別できるようにし、同じ数値を必ず
  表でも出しています。
- ライト／ダーク両方に対応（OS設定と、閲覧側のテーマ切り替えの両方に追従）。
- 見た目は「人を測る計測器」という見立てで組んでいます。ニュートラルは灰色ではなく
  わずかに青緑へ振ったインク色、角丸は2px、影は使わずヘアラインで区切り、
  数字とラベルはすべて等幅。レーダーの10角形をランクバッジや箇条の点に流用して
  モチーフとして反復させ、真鍮色は「1位」にだけ使っています。
- `native/` は iOS アプリ版（Capacitor）です。`npm run sync` で親フォルダの
  ウェブ版を取り込みます。アプリ内では Service Worker を登録しません
  （ファイルが端末内にあるため不要で、`capacitor://` では動作もしません）。
- PWA 化のためのファイルは `manifest.webmanifest` / `sw.js` / `icons/` です。
  Service Worker はページ本体をネットワーク優先（取れなければキャッシュ）、
  アイコンをキャッシュ優先にしています。Apps Script への通信には触りません。

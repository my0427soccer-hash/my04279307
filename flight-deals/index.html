羽田・成田発
格安航空券メモ

東京発の航空券の値段を毎日記録して、普段の相場から大きく外れた安値が出たときに 気づくための個人的な覚え書きです。

なぜ相場を記録するのか

航空券には、ごくまれに桁を間違えたような値段が出ることがあります。 羽田発ロサンゼルス往復が4万円台、といった水準です。多くは運賃の設定ミスや 為替換算の不具合が原因で、数十分から数時間で消えます。

こうした値段は「安いかどうか」を感覚で判断すると見逃します。 普段いくらなのかを知らなければ、5万円が安いのか高いのか分からないからです。 そこで日々の最安値を残し、相場の半額以下になった瞬間だけを 拾えるようにしています。

安値を見つけたときの実務

設定ミスによる運賃は、確保できても後から取り消されることがあります。 次の順で動くのが安全です。

  • すぐ買う。比較や相談をしている間に消えます
  • 発券まで確認する。予約番号だけでは確定ではありません。 eチケット番号が出て初めて発券済みです
  • しばらく他の予約を確定させない。取り消しの連絡は発券から 数日以内に来ることが多いので、ホテルや現地の手配はそれを待ってから
  • 予約内容を触らない。日程変更や座席指定で運賃が再計算され、 差額を請求されることがあります

表示価格には遅れがあります。ここから飛んだ先で値段が違っていれば、 その運賃は既に終わっています。粘らず次を待つほうが結果的に得です。

この記録の取り方

価格の取得から通知までは自作のツールで自動化しています。1日に複数回、 羽田・成田発の各路線・各月の最安値を取得して保存し、 中央値から大きく下振れした運賃が出たときだけメールが届く仕組みです。 ソースコードは GitHub に置いています。
